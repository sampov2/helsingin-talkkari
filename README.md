# Helsingin Talkkari

Rakastan Helsinkiä. Helsinki on kaunis, mielenkiintoinen ja monimuotoinen kaupunki. Kaupungilla liikkuessani tulee vastaan paikkoja jotka ovat unohdettuja ja huonossa kunnossa. Osa niistä ovat aiheutaa vain ärsytystä, mutta osa ovat potentiaalisesti vaarallisia kaupungin käyttäjille. Haluan meille kaikille parempaa Helsinki. Tämän projektin tavoitteena on antaa välineitä positiiviselle muutokselle elinympäristössämme.

## Prosessi

Kun havaitset jotain korjattavaa, tee seuraavat toimenpiteet:
1. Tarkista ettei havaintoa ole tehty jo - ei ole tarkoituksenmukaista raportoida useasti samaa ongelmaa https://palautteet.hel.fi/palautteet-kartalla
2. Tee vikailmoitus: https://palautteet.hel.fi/tunnistautuminen-uusi-vikailmoitus
    - Valitse käsittelyvaihtoehdoista sellainen, jossa saat linkin seurantasivulle
    - Anna lupa julkaista ellei ole painavaa syytä olla antamatta
3. Kirjaa uusi tiketti githubiin: https://github.com/sampov2/helsingin-talkkari/issues/new
    - Ilmoita milloin asia on raportoitu
    - Sisällytä raportoitu teksti ja kuvat
    - Lisää seurantasivulinkki
    - Label: palautteet.hel.fi (tai muu käytetyn palvelukanavan osoite/nimi)
    - Lisää tiketti projektille https://github.com/users/sampov2/projects/1 ja aseta tilaan "Ilmoitettu"
4. Seuraa asian käsittelyä
    - Kun palaute on käsitelty, siirrä github-tiketti tilaan "Reagoitu"
    - Kun palautteelle löytyy julkinen palautelinkki, lisää se tiketille
